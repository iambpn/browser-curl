Settings

Manage response limits and collection backups.

Response limits

1 MB is 1,024 KB. New requests use the saved values.

The extension stops reading a response body at this size. The panel then shows only the first part of the body.

History saves a response body only if the body is this size or smaller. For a larger body, history saves the request, status, and headers without the body. Enter 0 to never save response bodies.

Automatic disk sync

Back up saved collection changes to a folder you choose. Files use Postman JSON and replace earlier synced copies.

Save, import, rename, and edits to folders or requests trigger sync. Sending checks saved collections for pending backups. Unsaved request edits stay in the draft. Pending exports continue after the sidebar closes.

Files contain saved request credentials. Environment values stay on this device. File edits never load into browsercurl.

Each collection keeps its first sync filename, including after a rename. Deleting a collection keeps its disk file.

Your browser does not support automatic sync to a chosen folder. Use Chrome or Edge, or export collections manually.
