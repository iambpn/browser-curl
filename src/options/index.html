Settings

Size limits for response bodies. 1 MB is 1,024 KB. New requests use the saved values.

The extension stops reading a response body at this size. The panel then shows only the first part of the body.

History saves a response body only if the body is this size or smaller. For a larger body, history saves the request, status, and headers without the body. Enter 0 to never save response bodies.
