Your API, a little closer.

Paste a cURL command to fill in the request.

The editor did not use these parts of the command:

    Query parameters

    KEYVALUE

    Parameters are added to your request URL.

    Request headers

    KEYVALUE

    Cookie, Origin, Referer, and User-Agent are sent as you enter them. The browser sets Host, Content-Length, and Connection.

    Request body

    GET requests do not send a body. Select POST, PUT, PATCH, DELETE, or OPTIONS to enable the editor.

    Default Content-Type: application/json. A Content-Type in the Headers tab overrides this value.

    Authorization

    No credentials are added. You can still set an Authorization header in the Headers tab.

    Sent as an Authorization: Bearer header.

    Sent as an Authorization: Basic header. Use HTTPS to protect your credentials.

    Query keys appear in the request URL. Use a header if your API supports it.

    Enter the complete value, including the scheme, such as Token your-token.

    Credentials are saved locally with your draft, sent requests, and collections. The selected type overrides matching headers or query parameters.

    Drag or use the up and down arrow keys to resize the response. Home shrinks it. End expands it.

    SERVER OUTPUT
    Status Time Body Type Headers Final URL
